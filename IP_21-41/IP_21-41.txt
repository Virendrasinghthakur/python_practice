--- Slide 2 ---
Problem Statement
Write a Python program to filter odd numbers from a given dictionary keys. Display only those values which have odd keys.

--- Slide 4 ---
Algorithm
d = {1:"ali",2:"jafri",3:"zamir"}
for k,v in d.items():
    if k%2 != 0:
        print(v)
